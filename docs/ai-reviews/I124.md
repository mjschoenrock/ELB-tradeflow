## Fix applied
Repository HEAD before the change: `3e6d065`

Changed configuration:

```yaml
spring:
  kafka:
    producer:
      properties:
        enable.idempotence: true
```

Why this fix:
- Idempotent producers reduce duplicate Kafka writes when the producer retries after a transient broker/network issue.
- Combined with `acks: all`, this is a safer production posture for trade events.
